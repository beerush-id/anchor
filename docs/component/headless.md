# Headless Components

A headless component is a **logic unit without a view**. It encapsulates behavior — timers, keyboard shortcuts, connection managers, undo/redo controllers — as functions that return reactive state.

Because headless components are plain functions with no dependency on the view layer, they work inside components, outside components, in tests, and on the server.
