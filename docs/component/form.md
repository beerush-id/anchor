# Form Components

A form component is **user-driven**. Inputs own their values and update themselves on user interaction. The form collects, validates via Zod schemas, and submits. The developer binds to the form's reactive state — they don't micromanage each keystroke.

This follows the same model as native HTML forms, with the addition of schema-based validation and reactive state integration.
