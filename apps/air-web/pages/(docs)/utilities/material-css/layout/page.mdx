# Layout

While components represent the individual building blocks of your UI, your application needs a cohesive structure to organize them. The `layout` module in AirLib Material 3 CSS provides semantic structural classes to manage these overarching areas effectively.

Please select a layout element from the catalog below or the sidebar to view detailed usage guidelines, HTML structures, and CSS semantics.
