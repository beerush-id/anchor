# Installation

AirLib can be scaffolded instantly via `create airlib` or added manually to any existing Vite project.

## Quick Start

The fastest way to scaffold a full-stack AirLib application is using the official CLI:

:::code-group{group="pm"}
```bash [Bun] name="bun"
bun create airlib my-air-app
```

```bash [NPM] name="npm"
npx create airlib my-air-app
```

```bash [PNPM] name="pnpm"
pnpm create airlib my-air-app
```

```bash [Yarn] name="yarn"
yarn create airlib my-air-app
```
:::

Once scaffolded, start the local development server:

:::code-group{group="pm"}

```bash [Bun] name="bun"
cd my-air-app
bun install
bun dev
```

```bash [NPM] name="npm"
cd my-air-app
npm install
npm run dev
```

```bash [PNPM] name="pnpm"
cd my-air-app
pnpm install
pnpm dev
```

```bash [Yarn] name="yarn"
cd my-air-app
yarn install
yarn dev
```

:::

## Project Structure

A scaffolded project uses file-based routing and universal multi-runtime deployment out of the box:

```
my-air-app/
├── assets/                # Bundled media, SVGs, and images
├── components/            # Reusable UI components
├── pages/                 # File-based routes & layouts
│   ├── (docs)/            # Slave route (isolated tree with independent layout, guards, & providers)
│   ├── layout.tsx         # Main app layout wrapper
│   └── page.tsx           # Main landing / home page
├── public/                # Static assets served untouched
├── server/                # Multi-runtime Universal SSR entrypoints
│   ├── bun.js             # Bun runtime server
│   ├── node.js            # Node.js server (Hono)
│   ├── deno.js            # Deno runtime server
│   └── worker.ts          # Edge worker entry
├── src/                   # Application source & runtime setup
│   ├── api.ts             # IRPC client configuration & stubs
│   ├── app.css            # Global CSS styles & design tokens
│   ├── app.tsx            # Root application shell component
│   ├── client.tsx         # Client-side hydration bootstrap
│   ├── router.ts          # Client router configuration
│   ├── worker.ts          # SSR worker handler & request renderer
│   └── global.d.ts        # TypeScript declarations
├── index.html             # Universal HTML shell
├── vite.config.ts         # Vite configuration with airPages()
├── wrangler.toml          # Cloudflare deployment config
├── biome.json             # Code formatting & linting
└── package.json
```

## Vite Configuration

The `@airlib/vite` plugin handles route scaffolding, MDX compilation, metadata caching, and Universal SSR:

```typescript [vite.config.ts]
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import { airPages } from '@airlib/vite';

export default defineConfig({
  plugins: [react(), airPages()],
});
```

## Production Build

To build the client bundle and server bundle for production deployment:

:::code-group[Runtime engine]{group="runtime"}
```bash [Bun] name="bun"
# Build client and server bundles
bun run build

# Start production Bun server
bun start
```

```bash [Node.js] name="node"
# Build client and server bundles
npm run build

# Start production Node.js server
npm run start:node
```

```bash [Deno] name="deno"
# Build client and server bundles
npm run build

# Start production Deno server
npm run start:deno
```

```bash [Cloudflare] name="cloudflare"
# Build client and server bundles
npm run build

# Deploy to Cloudflare Worker
npx wrangler deploy
```
:::

## Manual Installation

If adding AirLib to an existing Vite application, follow these steps to install the packages and wire the universal entries:

### 1. Install Dependencies

:::code-group{group="framework"}

```bash [React] name="react"
# React dependencies
npm install @airlib/react @irpclib/irpc @irpclib/http react react-dom
npm install -D @airlib/vite @vitejs/plugin-react typescript vite @types/react @types/react-dom
```

```bash [SolidJS] name="solid"
# SolidJS dependencies
npm install @airlib/solid @irpclib/irpc @irpclib/http solid-js
npm install -D @airlib/vite vite-plugin-solid typescript vite
```

:::

:::tip[WebSocket Transport]
Standard RPC procedures and real-time streaming work over `@irpclib/http` out of the box. If your application specifically requires bidirectional stateful WebSockets, you can also install `@irpclib/ws`.
:::

### 2. Create the HTML Shell

Every page renders into `index.html`. Two comment markers designate where the server injects the document head and the rendered outlet:

```html [index.html]
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <!--ssr-head-->
  </head>
  <body>
    <div id="root" style="display: contents;"><!--ssr-outlet--></div>
    <script type="module" src="/src/client.tsx"></script>
  </body>
</html>
```

### 3. Create the Router

Create `src/router.ts` to initialize the root router instance:

:::code-group{group="framework"}

```typescript [React] name="react"
// src/router.ts
import { createRouter } from '@airlib/react';

const router = createRouter();
export default router;
```

```typescript [SolidJS] name="solid"
// src/router.ts
import { createRouter } from '@airlib/solid';

const router = createRouter();
export default router;
```

:::

:::tip[File-based Route Generation]
A folder defines a URL. `airPages()` watches your `pages/` directory and generates a `route.ts` per folder — `pages/route.ts` exports the `rootRoute` and `indexRoute` your layout and page import.
:::

### 4. Create the App Entry

Create `src/app.tsx` to render the root layout with the router:

:::code-group{group="framework"}

```tsx [React] name="react"
// src/app.tsx
import { type AppEntry, UIRouter } from '@airlib/react';
import RootLayout from '@/pages/layout.tsx';
import router from './router.ts';

export default (({ url }) => (
  <UIRouter router={router} root={RootLayout} url={url} />
)) satisfies AppEntry;
```

```tsx [SolidJS] name="solid"
// src/app.tsx
import { type AppEntry, UIRouter } from '@airlib/solid';
import RootLayout from '@/pages/layout.tsx';
import router from './router.ts';

export default (({ url }) => (
  <UIRouter router={router} root={RootLayout} url={url} />
)) satisfies AppEntry;
```

:::

### 5. Create the Client Hydration Entry

Create `src/client.tsx` to hydrate the app in the browser:

:::code-group{group="framework"}

```tsx [React] name="react"
// src/client.tsx
import '@airlib/react/client'; // must be first import

import { hydrateRoot } from 'react-dom/client';
import { acceptInteractions } from '@airlib/react/browser';
import App from './app.js';
import router from './router.js';

router.activate(window.location.href).then(() => {
  hydrateRoot(document.getElementById('root')!, <App />);
}).then(() => acceptInteractions());
```

```tsx [SolidJS] name="solid"
// src/client.tsx
import '@airlib/solid/client'; // must be first import

import { hydrate } from 'solid-js/web';
import { acceptInteractions } from '@airlib/solid/browser';
import App from './app.js';
import router from './router.js';

router.activate(window.location.href).then(() => {
  hydrate(() => <App />, document.getElementById('root')!);
}).then(() => acceptInteractions());
```

:::

### 6. Create the SSR Worker Entry

Create `src/worker.ts` to export the universal request handler:

:::code-group{group="framework"}

```typescript [React] name="react"
// src/worker.ts
import { createApp } from '@airlib/react/ssr';
import App from './app.js';
import router from './router.js';

export default createApp(router, App);
```

```typescript [SolidJS] name="solid"
// src/worker.ts
import { createApp } from '@airlib/solid/ssr';
import App from './app.js';
import router from './router.js';

export default createApp(router, App);
```

:::

### 7. Configure Vite

Add `airPages()` to your `vite.config.ts`:

:::code-group{group="framework"}

```typescript [React] name="react"
// vite.config.ts
import { airPages } from '@airlib/vite';
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [react(), airPages()],
});
```

```typescript [SolidJS] name="solid"
// vite.config.ts
import { airPages } from '@airlib/vite';
import { defineConfig } from 'vite';
import solid from 'vite-plugin-solid';

export default defineConfig({
  plugins: [solid({ ssr: true }), airPages()],
});
```

:::

### 8. Add Package Scripts

Add standard build and dev scripts to your `package.json`:

```json [package.json]
{
  "scripts": {
    "dev": "vite",
    "build:client": "vite build --outDir dist/client",
    "build:server": "vite build --ssr --outDir dist/server",
    "build": "bun run build:client && bun run build:server",
    "start": "bun run dist/server/worker.js"
  }
}
```
